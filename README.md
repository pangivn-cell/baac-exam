# ระบบซ้อมสอบ ธ.ก.ส.

เว็บซ้อมสอบไฟล์เดียว (`exam-practice.html`) เปิดใช้งานได้ที่ https://pangivn-cell.github.io/baac-exam/

- ฝึกทำข้อสอบ: ความรู้ความสามารถทั่วไป และความรู้เฉพาะตำแหน่ง ความยากปรับตามผล
- สอบจริง (Mock Exam): จับเวลา ส่งอัตโนมัติ ระบบกันโกง
- ประวัติสอบ และคลังความรู้: อัปโหลด PDF/DOCX/TXT/HTML ให้ AI ย่อยเป็นบัตรความรู้หรือดึงเป็นคลังข้อสอบ

ข้อมูลทั้งหมด (ประวัติ เอกสาร API key) เก็บในเบราว์เซอร์ของผู้ใช้แต่ละคนเท่านั้น ไม่ได้ส่งขึ้นเซิร์ฟเวอร์
ฟีเจอร์ AI ต้องใส่ Gemini หรือ OpenAI API key ของตัวเองในเมนู ตั้งค่า AI
