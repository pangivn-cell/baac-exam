# Baac_Exam ระบบซ้อมสอบ ธ.ก.ส.

เปิดใช้งานได้ที่ https://pangivn-cell.github.io/baac-exam/

- ฝึกทำข้อสอบ: ความรู้ความสามารถทั่วไป และความรู้เฉพาะตำแหน่งงานสินเชื่อ ความยากปรับตามผล
- สอบจริง (Mock Exam): จับเวลา ส่งอัตโนมัติ ระบบกันโกง
- คลังความรู้: อัปโหลด PDF/DOCX/TXT/HTML ให้ AI ย่อยเป็นบัตรความรู้หรือดึงเป็นคลังข้อสอบ แล้วแบ่งเข้าคลังกลาง (Firebase)
- สอบถาม AI, อันดับ, ประวัติสอบ, บันทึกโจทย์กันซ้ำ (ซิงก์ข้ามเครื่องเมื่อล็อกอิน)

ฟีเจอร์ AI ต้องใส่ Gemini หรือ OpenAI API key ของตัวเองในเมนู ตั้งค่า AI (key เก็บในเบราว์เซอร์เท่านั้น)

## โครงสร้างไฟล์

ไม่มีขั้นตอน build เป็น JavaScript ธรรมดา ทุกไฟล์ใช้ตัวแปรร่วมกัน **ต้องโหลดตามลำดับใน `index.html`**

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | โครงหน้า + เช็กเวอร์ชันใหม่ + โหลดไฟล์ด้านล่าง |
| `css/app.css` | หน้าตาทั้งหมด |
| `js/core.js` | ข้อมูลวิชา ตั้งค่าที่จำไว้ ตัวช่วยทั่วไป |
| `js/generators.js` | ตัวสร้างโจทย์ในเครื่อง: เงื่อนไขสัญลักษณ์ อนุกรม คณิต เงื่อนไขภาษา มิติสัมพันธ์ |
| `js/ai.js` | เชื่อมต่อ AI (Gemini / OpenAI / Claude) |
| `js/practice.js` | หน้าทำข้อสอบ สอบจริง กันโกง ประวัติสอบ |
| `js/questions.js` | บัตรความรู้ รูปประกอบ คลังข้อสอบ บันทึกโจทย์ และการสร้างชุดโจทย์ |
| `js/kb.js` | คลังความรู้: อ่านไฟล์ ประมวลผลด้วย AI อัปโหลด |
| `js/cloud.js` | Firebase: ล็อกอิน คลังกลาง ส่งเข้าคลัง ตรวจอนุมัติ |
| `js/visuals.js` | ระดับไม่จำกัด ตาราง/กราฟ/แผนที่ ทิศทาง การวิเคราะห์ข้อมูล |
| `js/views.js` | คะแนน อันดับ หน้าแรก สอบถาม AI เมนูมือถือ และเริ่มระบบ (ไฟล์สุดท้าย) |
| `exam-practice.html` | ที่อยู่เดิม พาไปหน้าใหม่ |
| `firestore.rules` | กฎฐานข้อมูล (แก้แล้วต้องเผยแพร่ใน Firebase console) |

ข้อควรระวัง
- โค้ดที่รันตอนโหลดหน้าแล้วเรียกฟังก์ชันจากไฟล์อื่น ให้ห่อด้วย `onAppReady(...)` (อยู่ใน `core.js`)
- ก่อนขึ้นเว็บทุกครั้ง: `sh bump.sh <เวอร์ชันใหม่>` เพื่อให้เบราว์เซอร์ทุกคนโหลดไฟล์ใหม่
- ทดสอบในเครื่องต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่น `python -m http.server --directory baac-exam`
